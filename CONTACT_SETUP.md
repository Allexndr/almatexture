## Как это работает

1. **Пользователь заполняет форму** на странице `/contacts`
2. **Сервер обрабатывает запрос** через API endpoint `/api/contact`
3. **Уведомление отправляется** в ваш Telegram мгновенно
4. **Сообщение логируется** в консоль сервера для резерва

## Альтернативные варианты

### 📧 Email уведомления (если захотите изменить)

Если в будущем захотите получать уведомления на email вместо Telegram, можно настроить SMTP:

```env
# В файл .env.local
SMTP_HOST="smtp.gmail.com"
SMTP_PORT="587"
SMTP_USER="your-email@gmail.com"
SMTP_PASS="your-app-password"
SMTP_FROM="noreply@yourdomain.com"
SMTP_TO="admin@yourdomain.com"
```

### 📱 Дополнительные Telegram каналы

Можно добавить отправку в несколько чатов/каналов, изменив код в `src/pages/api/contact.ts`.

## Тестирование

Для проверки работы отправьте тестовое сообщение через форму контактов на сайте или выполните:

```bash
curl -X POST http://localhost:3001/api/contact \
  -H "Content-Type: application/json" \
  -d '{"name":"Тест","email":"test@example.com","subject":"Проверка","message":"Тестовое сообщение"}'
```
