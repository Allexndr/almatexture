# AlmaTexture

AlmaTexture - платформа для создания текстильных изделий с текстурами Алматы. Проект сочетает городское наследие, традиции, моду и технологии.

## Обзор

Проект "Текстуры Алматы" представляет собой онлайн-каталог визуальных текстур города, разбитых по районам. Это сочетание фотографического искусства и краеведения, позволяющее по-новому взглянуть на знакомые места.

## Функциональность

- Каталог визуальных текстур, структурированный по районам города
- Галерея избранных текстур на главной странице
- Детальные страницы для каждой текстуры с информацией о местоположении
- Интерактивная карта расположения текстур (планируется)
- Онлайн-магазин с печатной продукцией (открытки, постеры, альбомы)
- Административная панель для управления контентом

## Технический стек

- Next.js (React фреймворк)
- TypeScript
- CSS Modules для стилизации
- Yarn для управления пакетами
- Prisma для работы с базой данных (опционально)

## База данных и интеграция

Проект использует PostgreSQL для хранения данных о текстурах, продуктах, районах и других элементах. Интеграция базы данных реализована с помощью ORM Prisma.

### Структура базы данных

- `textures` - текстуры города с привязкой к районам и тегам
- `districts` - районы города
- `products` - продукты/товары с текстурами
- `product_variants` - варианты продуктов (размеры, цвета)
- `tags` - теги для категоризации текстур
- `texture_tags` - связь между текстурами и тегами
- `users` - пользователи системы
- `orders` - заказы
- `order_items` - элементы заказов

### Специальные представления (views)

- `texture_products_view` - объединенный вид текстур и продуктов
- `filterable_products_view` - представление для удобной фильтрации продуктов

### API endpoints

- `/api/textures` - получение текстур с фильтрацией
- `/api/textures/[id]` - получение деталей текстуры
- `/api/products` - получение продуктов с фильтрацией
- `/api/products/[id]` - получение деталей продукта
- `/api/admin/textures` - административный API для текстур
- `/api/admin/sync-database` - синхронизация базы данных

### Скрипты для работы с базой данных

- `npm run sync-db` - запуск полной синхронизации базы данных
- `npm run import-textures` - импорт текстур из JSON
- `npm run import-products` - импорт продуктов из JSON

## Запуск проекта

### Требования

- Node.js 16+
- Yarn или npm

### Установка и запуск

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/yourusername/textures-almaty.git
   cd textures-almaty
   ```

2. Установите зависимости:
   ```
   npm install
   ```

3. Настройте окружение администратора:
   ```
   npm run setup-env
   ```

4. Настроить переменные окружения в .env файле
   ```
   DATABASE_URL="postgresql://postgres:cfif20041@localhost:5432/almatexture"
   ```

5. Запустите синхронизацию базы данных
   ```
   npm run sync-db
   ```

6. Запустите проект в режиме разработки:
   ```
   npm run dev
   ```

7. Или соберите и запустите в production-режиме:
   ```
   npm run build-and-start
   ```

Проект включает административную панель для управления контентом сайта.

### Доступ

1. После запуска приложения административная панель доступна по URL: `/admin`

2. Используйте следующие учетные данные для входа:
   - Email: admin@almatexture.kz
   - Пароль: almaty2023

### Возможности административной панели

- Управление товарами: добавление, редактирование, удаление
- Просмотр и управление заказами
- Настройка основных параметров сайта

Файл `scripts/setup-env.js` создает необходимые файлы конфигурации для административной панели. При необходимости вы можете изменить учетные данные администратора, отредактировав этот файл.
