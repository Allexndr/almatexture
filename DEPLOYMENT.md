# Деплой на Vercel

## 🚀 Быстрый деплой

### Шаг 1: Подключение GitHub

1. Перейдите на [vercel.com](https://vercel.com)
2. Войдите под аккаунтом **allexndr**
3. Нажмите **"Add New..."** → **"Project"**
4. Подключите свой GitHub аккаунт
5. Выберите репозиторий с проектом

### Шаг 2: Настройка переменных окружения

В разделе **Environment Variables** добавьте:

```env
MONGODB_URI=mongodb+srv://sanmemik2000:9dX2yUpRzso2A0MU@cluster0.aism76i.mongodb.net/
NEXT_PUBLIC_MONGODB_URI=mongodb+srv://sanmemik2000:9dX2yUpRzso2A0MU@cluster0.aism76i.mongodb.net/
```

### Шаг 3: Деплой

1. Нажмите **"Deploy"**
2. Vercel автоматически:
   - Скачает код
   - Установит зависимости
   - Соберет проект
   - Развернет на CDN

## 🔧 Возможные настройки

### Кастомный домен (опционально)

После деплоя можно добавить свой домен:
1. Domains → Add Domain
2. Добавить CNAME запись в DNS

### Аналитика (опционально)

Vercel предоставляет бесплатную аналитику:
- Количество посетителей
- Скорость загрузки
- География пользователей

## 📊 Мониторинг

- **Логи:** Vercel → Functions → View Function Logs
- **Ошибки:** Автоматические уведомления на email
- **Telegram:** Уведомления приходят в чат 5450018125

## 🔄 Автоматические обновления

При каждом push в main ветку GitHub:
- Vercel автоматически пересобирает сайт
- Деплой занимает 2-3 минуты
- Zero downtime deployment

## 🚨 Если что-то не работает

1. Проверьте логи в Vercel Dashboard
2. Убедитесь что MongoDB Atlas разрешает подключения с 0.0.0.0/0
3. Проверьте переменные окружения
